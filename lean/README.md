# Lean 4 formalization

This is a Lean 4 + Mathlib formalization of the main results of the paper "The order of growth of the Frobenius number of three consecutive k-th powers".

Versions: Lean `v4.36.0`, Mathlib `v4.36.0` (commit `fc4f59e577fe`, pinned in `lake-manifest.json`).

## What is formally proved

Every theorem below is checked by Lean with no `sorry` and no `native_decide`. `AxiomCheck.lean` prints the axioms used by 38 main declarations (listed in Appendix B of the paper). Each uses only the standard `propext`, `Classical.choice` and `Quot.sound`; in particular neither `sorryAx` nor `Lean.ofReduceBool` (the axiom behind `native_decide`) occurs.

Definitions:
- `FrobeniusNumber` is Mathlib's definition: the greatest natural number not in the additive submonoid generated by the set.
- `FrobCert.genus s` is the number of natural numbers not in that submonoid.
- `FrobCert.IsPF s x` means `x ∉ S` and `x + z ∈ S` for every nonzero `z ∈ S`.
- `GenK.gensPQ p q k n = {n^k, (n+p)^k, (n+q)^k}`, and `GenK.gensK k n = gensPQ 1 2 k n` generates S_n^k.
- `GenK.InL p q k n (i, j)` means `n^k ∣ i (n+p)^k + j (n+q)^k`, i.e. (i, j) lies in the relation lattice L_n^k(p, q).
- `GenK.supn (i, j) = max |i| |j|` is the maximum norm.
- `GenK.detZ u v` is the determinant of u and v.
- `GenK.IsRel c k P Z` means `X^k ∣ P (X+1)^k + Z (X+c)^k`, and `GenK.IsRelPQ p q k P Z` means `X^k ∣ P (X+p)^k + Z (X+q)^k`, in ℚ[X].

In the tables, S denotes ⟨a,b,c⟩, S_n denotes ⟨n⁴,(n+1)⁴,(n+2)⁴⟩, d₁ = ⌊k/2⌋, d₂ = ⌈k/2⌉ and e = k + ⌈k/2⌉. Section 6 of the paper (Table 1) gives the same correspondence in short form.

### Three generators in general

| Lean theorem | Statement | Paper |
|---|---|---|
| `FrobCert.frobenius_of_cert` | The certificate criterion gives the Frobenius number. | Lemma 2.1 (F) |
| `FrobCert.genus_uv` | The genus formula (2.3), in subtraction-free form. | Lemma 2.1 (genus) |
| `FrobCert.isPF_iff` | The pseudo-Frobenius numbers are exactly `ω(p) − a` for the maximal points p of the L-shape. | Lemma 2.1 (PF) |
| `FrobCert.pf_uv`, `FrobCert.type_uv` | If w, y ≥ 1 then PF(S) = {F₁, F₂} and the type is 2. | Lemma 2.1 (PF, type) |
| `FrobCert.pf_rect_uv` | If w = 0 or y = 0 then PF(S) = {F(S)}. | — |
| `FrobCert.exists_cert` | If 0 < a < c, 0 < b and gcd(a,b) = gcd(b,c) = 1, then parameters l, h, w, y, q₁, q₂ satisfying the hypotheses of Lemma 2.1 exist. | Remark 4.5 |
| `GenK.rep_of_box` | Box lemma: if the relation lattice of (a; b, c) contains two independent vectors of maximum norm ≤ R, every x ≥ 4R(b + c) lies in S. | Lemma 2.3 |
| `GenK.class_in_box`, `GenK.short_vectors_of_frob` | Covering lemma: every class meets [0, X]², X = ⌊(F + a)/b⌋, and the lattice contains two independent vectors of maximum norm ≤ 2X + 1. | Lemma 2.4 |
| `GenK.genus_le`, `GenK.frob_succ_le_two_genus` | For any numerical semigroup, g ≤ F and F + 1 ≤ 2g. | Sect. 2 |

The formal version of Lemma 2.1 assumes gcd(a, b) = 1, while the paper only assumes gcd(a, b, c) = 1. Every semigroup to which the paper applies the lemma satisfies gcd(a, b) = 1. The formal proof of Lemma 2.1 avoids the counting argument of the paper: points are moved into the L-shape by weight-decreasing steps, and two points of the L-shape with the same residue are shown to coincide by a lattice argument. The box lemma is proved by integer division in the basis u, v instead of real coordinates; otherwise the formal proofs of Lemmas 2.3 and 2.4 follow the paper.

### General k and shifted triples ⟨n^k, (n+p)^k, (n+q)^k⟩ (Sections 3 and 4)

| Lean theorem | Statement | Paper |
|---|---|---|
| `GenK.exists_rel` | If k < 2d + 2, there is a nonzero (P, Z) with deg ≤ d and `IsRel c k P Z`. | Prop. 3.1(a) |
| `GenK.normality` | If c ∉ {0, 1}, 2d + 2 ≤ k, deg P, deg Z ≤ d and `IsRel c k P Z`, then P = Z = 0. | Prop. 3.1(b) |
| `GenK.exists_basis_exact` | For c ∉ {0, 1} and k ≥ 2 there are relations V₁, V₂ with deg V₁ = d₁, deg V₂ = d₂ and det(V₁, V₂) = κ X^k, κ ≠ 0. | Prop. 3.1(c) |
| `GenK.transfer`, `GenK.exists_basisPQ` | The substitution x = p y turns relations for (x+1, x+q/p) into relations for (x+p, x+q); hence Prop. 3.1(c) holds for (x+p, x+q). | Prop. 3.1 |
| `GenK.exists_intBasis`, `GenK.vec_inL`, `GenK.detZ_vec` | Integer versions of V₁, V₂. For n ≥ 1, v₁(n), v₂(n) ∈ L_n^k(p, q) and det(v₁(n), v₂(n)) = K n^k with K ≠ 0. | Lemma 3.3 |
| `GenK.bezout3`, `GenK.dvd_detZ` | If gcd(n, p, q) = 1, the determinant of any two vectors of L_n^k(p, q) is divisible by n^k. | Sect. 2 |
| `GenK.lattice_minima` | For 0 < p < q there are γ > 0 and Γ such that for all n ≥ 1 with gcd(n, p, q) = 1: (i) some nonzero u ∈ L has ‖u‖∞ ≤ Γ n^{d₁}; (ii) every nonzero u ∈ L has n^{d₁} ≤ γ ‖u‖∞; (iii) there are u, v ∈ L with det ≠ 0 and ‖u‖∞, ‖v‖∞ ≤ Γ n^{d₂}; (iv) all u, v ∈ L with det ≠ 0 satisfy n^{d₂} ≤ γ max(‖u‖∞, ‖v‖∞). | Prop. 4.1, Theorem 1.2 (maximum norm) |
| `GenK.growthPQ` | For 0 < p < q and k ≥ 2 there are c, C such that for every n ≥ 2 with gcd(n, p, q) = 1 there is F with `FrobeniusNumber F (gensPQ p q k n)`, n^e ≤ c·F, F ≤ C·n^e, n^e ≤ 2c·g and g ≤ C·n^e. | Theorem 4.2 |
| `GenK.growth` | The case (p, q) = (1, 2): the same for S_n^k and all n ≥ 2. | Theorem 1.1 |
| `GenK.growthR` | For integers r₁ < r₂ < r₃ and k ≥ 2 there are c, C such that for every n ≥ 1 with n + r₁ ≥ 2 and gcd(n + r₁, r₂ − r₁, r₃ − r₁) = 1 the Frobenius number F of ⟨(n+r₁)^k, (n+r₂)^k, (n+r₃)^k⟩ exists and n^e ≤ c·F, F ≤ C·n^e, n^e ≤ 2c·g, g ≤ C·n^e. | Corollary 4.3 |
| `GenK.exists_frobenius` | For k ≥ 1 and n ≥ 2 the Frobenius number of S_n^k exists. | — |
| `GenK.emb_dim_three` | For k ≥ 1 and n > 2^k, none of n^k, (n+1)^k, (n+2)^k lies in the semigroup generated by the other two. | Cor. 1.3 (embedding dimension) |
| `GenK.cert_y_pos`, `GenK.cert_w_pos` | For k ≥ 2 and n ≥ 2^{k+1}, every certificate of S_n^k has w ≥ 1 and y ≥ 1. | Remark 4.5 |
| `GenK.pf_two`, `GenK.type_two` | For k ≥ 2 and n ≥ 2^{k+1}, PF(S_n^k) = {F₁, F₂} for a certificate (l, h, w, y), and the type is 2. | Cor. 1.3 (type) |
| `GenK.not_symmetric` | For k ≥ 2 and n ≥ 2^{k+1}, there is x ≤ F with x ∉ S_n^k and F − x ∉ S_n^k. | Cor. 1.3 (non-symmetry) |
| `GenK.type_two_odd`, `GenK.not_symmetric_odd` | The same for odd n > 2^k. | Cor. 1.3 (odd n) |

The polynomial part is proved for the pair (x+1, x+c) with a rational c ∉ {0, 1} and transferred to (x+p, x+q) by the substitution x = p y; the paper substitutes x = ps/(1−s) directly. In Prop. 3.1(c) a filtration by degree replaces the primitive part U of the paper. Theorem 1.1 and Theorem 4.2 are proved as in the paper, from Lemmas 2.3 and 2.4 and Prop. 4.1. Corollary 1.3 is proved without Herzog's theorem, by the argument of Remark 4.5. The constants of Theorems 1.1, 1.2 and 4.2 are only shown to exist; their explicit values in the paper are checked numerically by `check_constants.py`.

### k = 4 (Theorem 5.1, Corollary 1.5, Table A.5)

| Lean theorem | Statement | Paper |
|---|---|---|
| `FrobK4.class_r`, `FrobK4.classGP_r` (r = 0…39) | Frobenius number, genus, both PF numbers and type on each residue class mod 40. | Theorem 5.1 |
| `FrobK4.frobenius_k4_iff` | For n ≥ 2 outside the 36 exceptions of Table A.5: `FrobeniusNumber F S_n ↔ F = Φ_{n mod 40}(n)`. | Theorems 1.4, 5.1 |
| `FrobK4.genus_k4` | For n ≥ 2 outside 18 values: the genus equals the polynomial of Table A.4. | Theorem 5.1 |
| `FrobK4.pf_k4` | For n ≥ 2 outside the same 18 values: the PF numbers are exactly `PFa n`, `PFb n` (F₁, F₂ of (2.2)). | Theorem 5.1 |
| `FrobK4.type_k4` | For n ≥ 2 outside the same 18 values: the type is 2. | Theorem 5.1 |
| `FrobK4.*_ge_280` | All of the above for every n ≥ 280, with no exceptions. | Theorem 1.4 |
| `FrobK4.table5_correct` | Every row of Table A.5: Frobenius number, genus and the PF set. | Table A.5 |
| `FrobK4.frobenius_k4_exceptions` | At the 36 exceptions, F(S_n) ≠ Φ(n). | Table A.5 |
| `FrobK4.cor_limits` | For any F with `FrobeniusNumber (F n) S_n` for all n ≥ 2: liminf F(n)/n⁶ = 9/5, limsup F(n)/n⁶ = 26/5, liminf g(S_n)/n⁶ = 97/100, limsup g(S_n)/n⁶ = 13/5 (Mathlib's `Filter.liminf`, `Filter.limsup`). | Corollary 1.5 |
| `FrobK4.no_limit`, `FrobK4.exists_frob_fun` | F(S_n)/n⁶ has no limit; such an F exists. | Corollary 1.5 |

`check_lean_vs_paper.py`, one directory up, checks that the closed forms `Phi`, `Gam`, `PFa`, `PFb` and the list `table5` used here coincide with Tables A.3, A.4, A.5 and formula (2.2) of the paper. `make_tables_k4.py` checks that the printed Tables A.1–A.5 coincide with the output of `verify_k4.py`. These two checks are programs, not part of the formal proof.

## What is NOT formally proved

- The Euclidean form of Theorem 1.2. The maximum-norm form is proved, and the two are equivalent up to the factor √2.
- The explicit values of the constants in Theorems 1.1, 1.2 and 4.2. Lean only shows that the constants exist.
- The numerical data of Example 3.2, Remark 4.6, Table 2 and Remark 6.1.

## Files

- `Frobenius/Certificate.lean`, `Frobenius/Apery.lean` — the certificate criterion: Frobenius number, Apéry set, genus and pseudo-Frobenius numbers.
- `Frobenius/LShape.lean` — existence of the L-shape parameters for any ⟨a, b, c⟩ with a < c and gcd(a,b) = gcd(b,c) = 1.
- `Frobenius/GenKRelations.lean` — Proposition 3.1(a), (b) for the pair (x+1, x+c). The substitution is realised by homogenising and evaluating at (s, 1−s). The Rolle-type argument uses iterated derivatives.
- `Frobenius/GenKBasis.lean` — Proposition 3.1(c) for (x+1, x+c).
- `Frobenius/GenKLattice.lean` — the transfer to (x+p, x+q), Lemma 3.3, Proposition 4.1 and Theorem 1.2 for the maximum norm.
- `Frobenius/GenKGrowth.lean` — Lemmas 2.3 and 2.4, Theorems 4.2 and 1.1, Corollary 4.3, and the inequalities (F+1)/2 ≤ g ≤ F.
- `Frobenius/GenKType.lean` — Corollary 1.3.
- `Frobenius/K4Phi.lean`, `K4GP.lean`, `K4Classes.lean`, `K4ClassesGP.lean`, `K4Small.lean`, `K4.lean` — generated by `gen/gen_lean.py`, `gen/gen_gp.py` and `gen/gen_main.py` from the data of `verify_k4.py`. `gen_main.py` reads Table A.5 from the paper's LaTeX source.
  - `K4Classes.lean` and `K4ClassesGP.lean` each have 40 theorems, proved with `ring`, `positivity` and `omega`.
  - `K4Small.lean` has 317 numerical certificates for 2 ≤ n ≤ 318 (F, genus and PF). They are checked by `decide +kernel` with a Boolean checker whose soundness is proved (`NCert.sound`, `NCert.sound_genus`, `NCert.sound_pf`).
- `Frobenius/K4.lean` — assembles the k = 4 theorems, including Table A.5.
- `Frobenius/K4LimitsData.lean` — generated by `gen/gen_limits.py`, which reads the polynomials Φ_r and the genus polynomials from `K4Phi.lean` and `K4GP.lean`. It contains polynomial bounds of the form (9/5) n⁶ − K n⁵ ≤ Φ_r(n) ≤ (26/5) n⁶ + K n⁵, each proved by `linarith`.
- `Frobenius/K4Limits.lean` — Corollary 1.5. It contains a general lemma characterising `liminf` and `limsup` by such bounds.
- `AxiomCheck.lean` — prints the axioms used by the 38 main declarations.

The files `K4Phi`, `K4GP`, `K4Classes`, `K4ClassesGP`, `K4Small`, `K4` and `K4LimitsData` are generated by the scripts in `gen/`. All other files were written by hand.

## Build (Linux / macOS)

```bash
curl https://raw.githubusercontent.com/leanprover/elan/master/elan-init.sh -sSf | sh -s -- -y --default-toolchain none
```

```bash
cd lean
```

```bash
lake exe cache get
```

```bash
lake build
```

```bash
lake env lean AxiomCheck.lean
```

`lake exe cache get` downloads about 9100 precompiled Mathlib files. `lake build` checks the 16 project files in about 10 minutes on 4 cores, most of it in `K4Classes.lean`. Peak memory is about 9 GB. The output of `AxiomCheck.lean` is:

```text
'FrobCert.frobenius_of_cert' depends on axioms: [propext, Classical.choice, Quot.sound]
'FrobK4.frobenius_k4_iff' depends on axioms: [propext, Classical.choice, Quot.sound]
'GenK.growthPQ' depends on axioms: [propext, Classical.choice, Quot.sound]
'GenK.type_two' depends on axioms: [propext, Classical.choice, Quot.sound]
```

All 38 declarations listed in `AxiomCheck.lean` print the same three axioms; the excerpt above shows four of the lines.
